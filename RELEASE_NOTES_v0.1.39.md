**Detalhes da Versao:**

- Criada a tela `Sistema > Permissoes` para controlar excecoes individuais por usuario.
- Implementado suporte a permissoes por usuario com `Herdar`, `Permitir` e `Bloquear`.
- Aplicada prioridade segura para bloqueios manuais sobre o perfil base.
- Adicionada auditoria para alteracoes de permissoes individuais.
- Criadas permissoes especificas para relatorios financeiros, incluindo Pago x Recebido e Fluxo de Caixa.
- Ajustada a central de relatorios para exibir apenas os cards permitidos ao usuario.
- Ajustado o menu lateral para manter a area de Relatorios quando houver ao menos um relatorio liberado.
- Refinado o alinhamento do botao de salvar permissoes com o campo de confirmacao de senha.
